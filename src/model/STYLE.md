# 쇼츠 레퍼런스 스타일 분석 ("궤")

운영자가 만드는 쇼츠(커뮤니티 유머글을 화면에 띄워 읽어주며 반응하는 형식)와 같은 결의 글을 고르기 위한 기준 문서.
짝 파일: `reference-shorts.json` (쇼츠 제목 1,148개, 분류 포함). 수집일 2026-10-17, 조회수는 그날 값.

---

## 0. 자료와 방법

- **수집**: YouTube 공개 페이지 GET 만 사용 (로그인·API 키 없음). HTML 안의 `ytInitialData` JSON 을 파싱. 총 47회 요청
  (YouTube 45 + 이 사이트 공개 목록 API 2). 원본 HTML 은 저장소에 넣지 않았다 (수집할 때의 임시 폴더에만 있었다).
- **채널당 3가지 목록**: Shorts 탭(최신 48개) + 자동 재생목록 `UUSH…`(쇼츠 최신 100) + `UUPS…`(인기 쇼츠 100).
  인기 목록이 있어서 "조회수가 실제로 나온 쇼츠"의 소재 비중을 따로 볼 수 있다.
- **기준 3채널** (운영자가 보여준 쇼츠의 채널, 모두 버튜버가 유머글을 읽는 형식):
  - 도롱챠 DOLONGCHA (구독 23.2만): "충청도인이 겪은 역대급 충청도식 프로포즈" (19초, 설명란 태그 `#유머글 #리액션`)
  - 코리수의게임세상 (31.4만): "작가와 독자의 기싸움 레전드썰ㄷㄷ" (60초, `#코난 #기싸움`, 코난 작가와 독자 이야기)
  - 허니가루비 (18.2만): "일본사람이 물어보고 싶었던 한국 표현" (29초, `#유머글 #커뮤니티`)
- **비슷한 채널 5개**: 검색 결과 쇼츠의 채널 ID(`reelWatchEndpoint.params` 안에 들어 있음)를 풀어서, 같은 원글을 다룬 채널을 찾았다.
  - 김블루 (도롱챠와 소재·제목 방식이 가장 비슷), 방구석귀요미 (훈훈한 당근·사장님 글), 똘킹 (`.jpg` 캡처 읽기, 금지 소재가 섞여서 35% 제외),
    심심한 회사원 (인증 짤 모음, 사진 비중 높음), 김켈리 (애니 콩트·교양이 대부분이라 글 읽기형 16개만 남김)
- **대조 채널 3개** (형식은 같은 "커뮤니티 글 읽기"인데 궤가 다른 곳, JSON 에는 넣지 않고 숫자 비교에만 씀):
  짤짤톡톡 (연애·남녀 갈등 사연), 커뮤킹 (이슈·스포츠 "근황..ㄷㄷ"), 숏토리 (논쟁·갈등 사연)
- **후보였지만 뺀 채널**: 웃긴댓글 (영상 클립 + 댓글), 헛소리 (병맛 더빙), 마로니 (본인 이야기 애니), 누눙지 (주식), 스튜디오 유니코 (예능 클립)
- **분류**: 제목 키워드 규칙으로 1차 분류 → 사람이 제목을 읽고 33건 바로잡음 (규칙 자체도 여러 번 고침). 운영자 금지 소재는 보수적으로 뺐다
  (애매하면 뺌. 예: 제목에 "남자가/여자들", "헤어지", "빡친", "논란인 연예인" 등).
- **결과**: 수집 1,907개 → 기준셋 1,148개 (기준 3채널 534 + 유사 614). 기준 3채널 596개 중 62개(10.4%)는 금지·비유머라 제외.
  해시태그는 제목에서 지웠다. 김켈리 제목 122개는 한글이 자모 분리(NFD)라서 NFC 로 정규화했다.

## 3. 형식

- **길이**: 기준 쇼츠 3개가 19초·60초·29초. 글로 치면 캡처 1~3장, 대화 10줄 안팎, 썰이면 300~600자 정도.
- **글이 주인공**: 대화·댓글·리뷰·질문과 답·짧은 썰을 읽는 것만으로 웃음이 완성된다. 사진은 보조.
  (유사 채널 중 똘킹·심심한 회사원은 `.jpg`·인증 짤 모음이 많다. 사진만으로 웃긴 글은 2순위다.)
- **원출처가 제목에 거의 안 나온다**: `sourceHint` 가 있는 건 1,148개 중 114개(9.9%). 나올 때는
  당근마켓 27 · 배달앱 20 · 카톡 13 · 문자 13 · 디시 갤러리 7 · 리뷰 6 · 에브리타임 4 · 중고나라 4.
  즉 캡처 매체로는 **앱 속 대화·리뷰·문자**가 흔하다.
- **쇼츠 제목은 다시 쓴 제목이다**: 기준 3채널 제목 중앙값 19자. "썰"이 들어간 제목은 0.5%, "카톡·대화·문자"는 1.2%뿐이다.
  원글 제목에 "썰/카톡/.jpg" 가 있는지보다, **내용을 "~한 ~" 한 줄로 바꿔 쓸 수 있는지**가 궤에 가깝다.
- 같은 원글을 여러 채널이 쓴다 (예: "최악의 키보드 모음"은 김블루·똘킹이 각각 1,200만 회 넘게 나왔다). 이미 쇼츠에서 돈 글과 비슷한 글은 강한 후보다.

## 6. 지금 사이트 선별과 어긋날 만한 점

(2026-10-17 공개 API `GET /api/posts?board=story|pick` 기준. 소소한 이야기 23개, 소소한 웃음 78개)

1. **소소한 이야기가 너무 적다 (23개).** 조건이 `Claude 판정 ok AND shortsScore ≥ 55 AND vibe ≥ 70` 로 모두 걸려 있다. 쇼츠의 궤는 더 넓다.
2. **호기심·잡학 축이 빠져 있다.** 기준 3채널 균등 16.7% (도롱챠·코리수만 보면 23%)가 "…인 이유 / 의외로 … / …의 정체 / 신기한 물건·음식·동물"이다.
   그런데 `ai.js` 는 "정보/지식"을 `not_humor` 로 두고, vibe 는 사진이 웃음 포인트면 0~49 로 둔다.
   현재 소소한 이야기 23개 중 잡학은 1개(4%)이고 사투리·말장난·동물·학교는 0개다 (외국인 30%, 황당 35%는 쇼츠와 비슷하다).
   → **웃음 대신 "신기한 이유"로 끝나는 가벼운 잡학은 통과**시켜야 쇼츠와 같아진다. 건강·재테크·꿀팁 정보글은 계속 뺀다.
3. **키워드 가산점이 궤와 반대 방향이다.** `filter-rules.js` `SHORTS_SIGNALS` 의 참교육 +10, 역관광 +10, 사이다 +7, 진상 +8, 억울 +6, 킹받 +8, ㅋㅋ +6.

## 9. `reference-shorts.json` 형식

```json
{ "title": "센스도 필요해진 당근 거래", "channel": "도롱챠 DOLONGCHA", "views": 2500000,
  "url": "https://www.youtube.com/shorts/2dKJMH551ec", "category": "중고거래·당근", "sourceHint": "당근마켓" }
```

- 1,148개, 채널 순서(기준 3채널 → 유사 채널) 안에서 조회수 내림차순. `views` 는 수집일 값(정수), `sourceHint` 는 제목에 보이는 원출처·매체일 때만 넣고 없으면 `null`.
